# ✍️ academic-paragraph-openings

**中文学术论文段首写作 Skill** · 适用于 Codex

帮助你判断论文每个段落应该如何起笔，让第一句接住上文、明确本段任务，并与后面的证据和论述相匹配。

它从七篇中文论文中整理了 **21 个带 PDF 页码的代表性样本**，涵盖语言教学、推荐系统综述和传播理论。学习重点是段首承担的论证功能，以及段落之间如何推进。

## 🧭 它能帮你做什么

| 场景 | 处理方式 |
| --- | --- |
| 只修改段首 | 按原段落顺序提供替换句，尽量保留其余正文 |
| 逐段诊断 | 对照原段首、本段任务、建议写法及其与后文的关系 |
| 检查段间衔接 | 找出重复立论、指代不清、跳跃和没有依据的转折 |
| 根据材料起笔 | 选择界定、判断、提问、比较、例证或限定等切入方式 |
| 学习论文范文 | 分清原文、功能分析与原创迁移示范 |

适用于理论论文、文献综述、技术综述、实证论文，以及案例和历史叙述。这里的“段首”指正文各段的开头，也包括小节起笔，并不限于整篇论文的引言。

## 💡 核心思路

改写之前，先读完整段落，再回答三个问题。

1. **上文已经说到哪里？** 找到已经完成的讨论和尚未解决的问题。
2. **本段增加了什么？** 明确它是在解释、比较、举证、限定，还是转入下一项任务。
3. **后文支持多大的判断？** 保留样本范围、条件和不确定性，让段首与证据相称。

有效的段首可以保留。例证段、史实段和方法段也可以直接从材料或操作起笔，无须全部改成概括性观点句。

## 📦 安装

下载本仓库，将包含 `SKILL.md` 的整个文件夹命名为 `academic-paragraph-openings`，放到本机的 Codex skills 目录。

默认目录结构如下；如果你配置了 `CODEX_HOME`，请使用其下的 `skills` 目录。

```text
~/.codex/skills/
└── academic-paragraph-openings/
    ├── SKILL.md
    ├── README.md
    ├── agents/
    │   └── openai.yaml
    └── references/
        └── source-patterns.md
```

这是由 Markdown 指令与参考材料组成的技能，无须安装 Python 包或运行项目脚本。修改文章时不依赖原始论文 PDF。

## 🚀 使用示例

安装并确认技能可用后，在对话中指定技能名称，再附上待处理文本。

### ✂️ 只改每段第一句

```text
使用 $academic-paragraph-openings，修改下面这些段落的开头句。
请先阅读每段全文，按原段落顺序给出替换句，保留数字、引文和作者立场。
有效的段首可以保留；如需联动修改第二句，请单独说明。

[粘贴正文]
```

### 🔎 逐段检查论证

```text
使用 $academic-paragraph-openings，逐段诊断这一节的段首。
用“原段首／本段任务或问题／建议段首／与后文的关系”展示。
重点检查重复立论、转折依据和段首判断是否超过证据范围。

[粘贴小节标题与正文]
```

### 🔗 检查连续段落的推进

```text
使用 $academic-paragraph-openings，检查这些段落之间怎样衔接。
先说明每段新增的内容，再修改确有问题的开头句。
不要为了句式多样化而改动已经清楚的表达。

[粘贴连续段落]
```

> 📝 提供完整段落，以及前一段结尾、后一段开头和所属小节标题，更有助于判断衔接。只提供一句话时，技能只能可靠地处理句子本身。

## 🧪 一个改写示范

以下是**假设材料**，用于说明改写方法，并非真实研究发现。

**材料**：三个受访者提到，自动字幕节省了初步转写的时间，但专有名词仍需人工核对。

**原段首**

> 人工智能全面重塑了影视行业的生产格局。

**建议段首**

> 在这三位受访者的叙述中，自动字幕主要用于缩短初步转写所需的时间。

改写后，句子明确了对象、样本和作用范围。后文可以继续解释人工核对的必要性，而不必承担证明整个行业已经发生全面变革的任务。

详见 [21 个样本及其功能分析](references/source-patterns.md)。这些样本是代表性观察，不是对七篇论文所有自然段的穷尽标注，也不是写法频率的统计结果。

仓库提供必要的原文摘录、出处与写法分析，不包含原始论文 PDF。论文摘录的权利归原作者及相应权利人所有；样本中的技术观点与历史数据不作为当前事实的核验依据。

## 🎯 使用边界

- 不编造数据、引文或研究发现。
- 不将相关关系改写成因果关系，不随意提升判断的确定程度。
- 不默认重写全文，也不强迫所有段落使用同一种结构。
- 不以机械替换连接词、堆砌术语或改动数量衡量质量。
- 不承诺提升录用率、降低检测分数或判断文本的作者身份。

判断修改是否有效，可以回到一个具体问题：**读完段首，后文是否真正完成了它提出的任务？**
